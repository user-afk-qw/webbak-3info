📋 Задание №3

Веб-форма с валидацией и сохранением данных в MySQL

📌 Описание задания

Разработать HTML-форму с 9 полями (ФИО, телефон, email, дата рождения, пол, любимые языки программирования, биография, чекбокс контракта).

Реализовать серверную валидацию всех полей с выводом понятных ошибок.

Сохранять данные в базу данных MySQL с использованием подготовленных запросов (Prepared Statements).

База данных должна быть в 3-й нормальной форме (3 таблицы).

🗄️ Структура базы данных (3-я нормальная форма)

База данных состоит из 3 таблиц, что соответствует 3-й нормальной форме:

  • applications — основная таблица с данными заявки (автоинкрементный id)
  • programming_languages — справочник языков программирования
  • application_languages — связующая таблица (один ко многим)
